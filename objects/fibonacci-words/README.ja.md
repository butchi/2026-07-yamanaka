# フィボナッチ語（フィボナッチ文字列）

Fibonacci word の訳語には「フィボナッチ語」と「フィボナッチ文字列」が使われます。この項目では、整数の加算ではなく文字列の連結によって作る、2種類の記号からなる有限語の初期項を、各項とも文字列として記録します。

## 定義

`W_0 = "0"`、`W_1 = "01"` とし、`n >= 2` では `W_(n-1)` の後ろに `W_(n-2)` を連結したものを `W_n` とします。データは添字を0から始め、各語をJSON文字列として保存します。

## 範囲

公開データは最初の7項です。任意の長さの語を生成する実装ではなく、有限の参照データです。
