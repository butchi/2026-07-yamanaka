# Golden ratio

The golden ratio is the positive irrational solution of $`x^2 = x + 1`$. Its exact value is

$$
\varphi = \frac{1 + \sqrt{5}}{2}.
$$

The digest stores a truncated JSON-number approximation with 16 digits after the decimal point. The standard dataset stores the ordinary decimal notation as a string with 256 digits after the decimal point, preserving every digit. Neither finite decimal is the exact value.

The exact value is also available as Content MathML in `data/value.json`.

## Properties

- $\varphi^2 = \varphi + 1$
- $\varphi^{-1} = \varphi - 1$
- $\varphi$ is irrational.
- The ratios of consecutive Fibonacci numbers converge to $\varphi$.
