# Golden ratio

The golden ratio is the positive irrational solution of $`x^2 = x + 1`$. Its exact value is

$$
\varphi = \frac{1 + \sqrt{5}}{2}.
$$

The decimal shown on this page is a finite approximation, not the exact value. The JSON value contains 50 digits after the decimal point.

## Properties

- $\varphi^2 = \varphi + 1$
- $\varphi^{-1} = \varphi - 1$
- $\varphi$ is irrational.
- The ratios of consecutive Fibonacci numbers converge to $\varphi$.
