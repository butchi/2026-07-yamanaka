# 黄金比

黄金比は、$`x^2 = x + 1`$ を満たす正の無理数です。厳密値は次のとおりです。

$$
\varphi = \frac{1 + \sqrt{5}}{2}.
$$

ダイジェストには小数点以下16桁で打ち切ったJSON数値の近似値を保存します。標準データには通常の10進表記を文字列で保存し、小数点以下256桁をすべて保持します。どちらの有限小数も厳密値そのものではありません。

厳密値は `data/value.json` にContent MathML形式でも収録しています。

## 性質

- $\varphi^2 = \varphi + 1$
- $\varphi^{-1} = \varphi - 1$
- $\varphi$ は無理数です。
- 隣り合うフィボナッチ数の比は $\varphi$ に収束します。
