# 黄金比

黄金比は、$`x^2 = x + 1`$ を満たす正の無理数です。厳密値は次のとおりです。

$$
\varphi = \frac{1 + \sqrt{5}}{2}.
$$

ページに表示する小数は有限桁の近似値であり、厳密値そのものではありません。JSONには小数点以下50桁を収録しています。

## 性質

- $\varphi^2 = \varphi + 1$
- $\varphi^{-1} = \varphi - 1$
- $\varphi$ は無理数です。
- 隣り合うフィボナッチ数の比は $\varphi$ に収束します。
