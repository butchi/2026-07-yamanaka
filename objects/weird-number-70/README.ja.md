# 不思議数 70

70は最小の不思議数です。「過剰数である」だけでは不思議数にならないことが分かる、分類上の境界例でもあります。

## 定義

正の整数の真の約数とは、その数自身を除く正の約数です。真の約数の和が元の数を超える数を過剰数といい、真の約数の部分集合の和が元の数に一致するとき擬似完全数といいます。不思議数は、過剰数であり、かつ擬似完全数ではない数です。

データには70と12の対照例を記録しています。70の真の約数の和は74ですが、約数のどの部分集合も70になりません。一方、12の真の約数の和は16で、部分集合 `2, 4, 6` の和は12です。そのため12は過剰数ですが、不思議数ではありません。

## 範囲

この項目は最小の不思議数と分類の対照例を記録するデータオブジェクトであり、不思議数全体の一覧ではありません。
